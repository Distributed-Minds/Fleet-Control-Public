# FREE ENERGY — Phase0 Preview v0.1.2

This preview establishes **FREE ENERGY** as the canonical public identity of the project.

> **Federated Remastering Ecosystem for Everyone — Engine for Networked Entertainment, Remixing, Games & You**

> **FREE ENERGY Remasters Everything.**

## Naming model

- **FREE ENERGY** is the public project, community, future website, and broader collaborative game-remastering/remixing ecosystem.
- **Fleet-Control** remains the name of the orchestration substrate and repository-local agent coordination model.
- **Phase0** remains the current Markdown-first bootstrap implementation.

The GitHub repository may temporarily retain the legacy `Fleet-Control-Public` slug while repository and website identifiers are migrated. Historical tags, links, issues, branches, and protocol references are not rewritten merely for cosmetic consistency.

## Packaging changes

The preview starter artifact is now named `FREE-ENERGY-Phase0-Starter-v0.1.2-preview.zip` and includes `BRANDING.md`.


## Installation advisory — added 2026-10-08 (not part of the published ZIP)

The published [v0.1.2 starter ZIP](https://github.com/Distributed-Minds/Fleet-Control-Public/releases/tag/v0.1.2-phase0-preview) is a fixed historical artifact. Its bundled instructions predate the corrected [online Getting Started guide](https://github.com/Distributed-Minds/Fleet-Control-Public/blob/phase0/public-v0/GETTING-STARTED.md). Upstream `main` contains a landing README but **not** the installable `Phase0/` files. A default-branch-only fork therefore misses Phase0. Either fork **all branches** and set **your fork's** default branch to `phase0/public-v0`, or copy the release ZIP's `Phase0/` directory into a repository you control. Before enabling scheduled agents, verify `Phase0/05-FLEET-CONFIG.md` is present on **your repository's default branch**.

For installations from that historical ZIP, copy the [public Phase0 MIT notice](https://github.com/Distributed-Minds/Fleet-Control-Public/blob/phase0/public-v0/LICENSE) to `Phase0/LICENSE` before committing, because the ZIP predates that in-package addition. **Do not replace the receiving project's root `LICENSE`** or assume its unrelated files share Phase0's license. Verify the ZIP against its corresponding [SHA-256 checksum file](https://github.com/Distributed-Minds/Fleet-Control-Public/releases/download/v0.1.2-phase0-preview/FREE-ENERGY-Phase0-Starter-v0.1.2-preview.zip.sha256) as described in the online guide. A matching checksum alone does not authenticate the publisher.

This advisory does not alter the already-published ZIP, its checksum, the release tag, or the original bundled instructions.

## Functional scope

This release is a branding/onboarding migration. It does **not** claim a new Fleet-Control protocol generation merely because the public project name changed.
