02 / AVAILABLE NOW

Start with a fleet.
Build toward an ecosystem.

The first public piece is Fleet-Control Phase0: a Markdown-first operating protocol for persistent GitHub-connected AI agents. It is a bootstrap, not a hosted game marketplace, build cloud, or finished remastering platform.

Download the starter ZIP ↗

The v0.1.2 ZIP contains an older setup guide. Follow the corrected online guide before installing or forking.

Phase0 documents a protocol for:

  • ✓ Persistent agent identities and behavior modes
  • ✓ Planning, adversarial review, and verification
  • ✓ GitHub-based coordination and ownership
  • ✓ Human-controlled default-branch integration

Documented rules are not guarantees that every external tool or agent mechanically enforces them.

    Choose your installation route

    Either fork all branches and set phase0/public-v0 as your fork's default, or install the starter ZIP into a repository you control. Forking the upstream default branch alone does not install Phase0; follow the current setup guide to verify the Phase0/ files.

    Follow the setup

    The beginner guide explains GitHub, ChatGPT Projects, and automations step by step.

    Make work reusable

    Start in your own repository. Preserve issues, decisions, research, fixes, and handoffs as durable artifacts.
