02 / AVAILABLE NOW

Start with a fleet.
Build toward an ecosystem.

The first public piece is Fleet-Control Phase0: a Markdown-first operating protocol for persistent GitHub-connected AI agents. It is a bootstrap, not a hosted game marketplace, build cloud, or finished remastering platform.

Download the starter pack ↗

Phase0 documents a protocol for:

  • ✓ Persistent agent identities and behavior modes
  • ✓ Planning, adversarial review, and verification
  • ✓ GitHub-based coordination and ownership
  • ✓ Human-controlled default-branch integration

Documented rules are not guarantees that every external tool or agent mechanically enforces them.
