# Security and privacy reporting (Phase0 preview)

This notice documents the current public-reporting boundary. It is **not** a
confidential intake channel, a claim that GitHub private vulnerability reporting
is enabled, or a guarantee of response, remediation, or disclosure timing.

## Public channels are not confidential

GitHub Issues, Discussions, pull requests, review comments, and public commits
in this repository can be read by other people. Do **not** post credentials,
access tokens, private repository material, personal information, proprietary
game files, or sensitive exploit details in any of these surfaces.

A narrowly described, non-sensitive documentation or security-process question
may be appropriate for a public channel, but omit vulnerable endpoints,
reproduction payloads, proof-of-concept exploits, and any confidential evidence.
Do not use a public issue to deliver a private vulnerability report.

## Confidential reporting status

**No maintainer-verified confidential security-reporting route is currently
documented for this preview.** Do not assume that the existence of this file
means such a route exists. GitHub's private vulnerability-reporting option is
usable only if it is actually enabled for this repository and the reporter can
verify that the submission is private. If no suitable verified private route is
available, withhold sensitive details rather than putting them in public posts.

The outstanding confidential-intake and separately authorized release-control
requirements are tracked in [public issue #38](https://github.com/Distributed-Minds/Fleet-Control-Public/issues/38).
That issue is a **status and design tracker**, not a confidential disclosure
channel. Its retirement of the former Rehoboam public-exposure gate does not
waive security, privacy, consent, or rights obligations.

## Scope of this notice

FREE ENERGY's available Phase0 is a Markdown-first orchestration preview. This
file does not assert that a hosted service, production dispatcher, game catalog,
security response team, or private reporting service already operates. Any
future confidential intake instructions should be added only after maintainers
verify the actual access controls and reporting path.
