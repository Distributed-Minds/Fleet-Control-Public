# FREE ENERGY — canonical public identity

## Canonical name

**FREE ENERGY**

Expansion:

> **Federated Remastering Ecosystem for Everyone — Engine for Networked Entertainment, Remixing, Games & You**

Tagline:

> **FREE ENERGY Remasters Everything.**

## Naming boundary

Use **FREE ENERGY** for the public project, community/ecosystem, future website, user-facing onboarding, public releases, starter packages, and the broader game-remastering/remixing mission.

Use **Fleet-Control** for the orchestration substrate: repository-local agent authority, coordination, lifecycle, state-machine, and control machinery.

Use **Phase0** for the current Markdown-first public bootstrap implementation.

## Migration rule

The canonical brand changes before every infrastructure identifier has to change.

During migration, references such as the GitHub slug `Distributed-Minds/Fleet-Control-Public`, existing release tags, historical issue titles, branch names, and protocol terms may retain the old name when changing them would break links, provenance, automation, or history.

Do not rewrite historical artifacts merely to erase the old name. New public-facing material should prefer **FREE ENERGY** unless it is specifically naming the Fleet-Control substrate.

## Product direction

FREE ENERGY is intended to become a collaborative system in which humans and agent fleets can reuse durable work across many game projects: research, source ports, compatibility fixes, build knowledge, assets, tools, remasters, mods, experiments, and eventually higher-level mashups.

The scope is deliberately broader than an IDE. The public product may eventually include repository discovery, project graphs, fleet orchestration, build/test infrastructure, provenance and licensing information, reusable asset catalogs, playable artifacts, contribution discovery, and development interfaces.

Current repository contents do not imply that all of those surfaces already exist.
