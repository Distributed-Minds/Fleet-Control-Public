# Fleet-Control Public — Phase0 Preview v0.1.1

This preview supersedes v0.1.0 for new installations.

## What changed

The public Phase0 implementation is now explicitly licensed under the **MIT License** with:

`Copyright (c) 2026 Distributed Minds`

The human starter ZIP for this release includes the root `LICENSE` file, so people who download only the starter package receive the license terms together with the operating system and setup material.

No existing public tag was moved. The v0.1.0 preview remains an immutable historical snapshot of the earlier package.

## New users

Download the asset named:

`Fleet-Control-Public-Phase0-Starter-v0.1.1-preview.zip`

Extract it and open `README-FIRST.md`, then `GETTING-STARTED.md`.

The starter package contains:

- the complete `Phase0/` Markdown operating system;
- `LICENSE`;
- beginner setup documentation;
- a glossary and troubleshooting guide;
- ChatGPT Project instructions;
- separate A1 through A5 persistent automation prompts;
- installation checklist and templates.

You do not need prior Git or GitHub command-line experience to follow the beginner path.

## Existing v0.1.0 users

If you already downloaded the v0.1.0 starter, use v0.1.1 instead so your local copy includes the explicit MIT terms.

## Status

This remains a preview. The public state-machine and coordination model is intentionally being tested and generalized before a stable release. Public-safe improvements from the private Fleet-Control development repository may be carried forward into later public versions after portability and disclosure checks.
