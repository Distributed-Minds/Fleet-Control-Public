# FREE ENERGY — game project workflow guides

**Choose the work you want to do**, then follow the relevant references. This is a curated navigation page, not a new agent operating system or a claim that FREE ENERGY already supports every listed workflow.

**What exists today:** [Fleet-Control Phase0](Phase0/README.md), a Markdown-first GitHub-connected agent coordination starter. To install it in **your own** repository, use the [FREE ENERGY getting-started instructions](GETTING-STARTED.md) and the [current starter release](https://github.com/Distributed-Minds/Fleet-Control-Public/releases). The first playable catalog, game-specific adapters, hosted services and cross-game platform remain proposed work; see [catalog #60](https://github.com/Distributed-Minds/Fleet-Control-Public/issues/60) and the [FIND → PLAY → IMPROVE → REMIX product direction #63](https://github.com/Distributed-Minds/Fleet-Control-Public/issues/63).

## Before relying on a guide

1. **Check the actual project, target game, operating system and release versions.** The upstream guides are explicitly drafts. Loader support, model pricing, availability and platform compatibility change.
2. **Separate technical feasibility from permission.** Source code, textures, audio, game files, tools, screenshots and trademarks can have different owners/licensing. A user owning a game does not grant a project general redistribution rights. The upstream legal pages are not legal advice or project-specific clearance.
3. **Know whose rules apply.** These guides primarily address single-player/offline modding of games participants own. Do not silently convert that guide-specific scope into FREE ENERGY's entire future product scope. Conversely, do not infer online/anti-cheat/DRM work is approved: each proposed integration needs its own feasibility, platform policy, permission and safety checks.
4. **Keep the agent control plane separate.** The upstream [`AGENTS.md`](https://github.com/trevaintdead/ai-game-modding-guides/blob/main/AGENTS.md) and starter prompts are examples. They do **not** supersede this repository's [Phase0 authority](Phase0/README.md), permissions, task coordination, privacy rules or human merge decisions.
5. **Turn repeated questions into durable results.** Search before starting over; publish precise bug reports, negative results, known-good versions, tests, manifests and provenance. Distinguish **observed, derived, predicted and unknown**.
